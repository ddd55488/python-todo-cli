# Python 命令行待办事项管理器

一个适合初学者阅读的小项目：添加任务、查看列表、标记完成，并将任务保存为本地 JSON 文件。

## 运行

需要 Python 3.10 或更新版本，无第三方依赖。本次实际验证环境：Windows、Python 3.14.7。

```powershell
git clone https://github.com/ddd55488/python-todo-cli.git
cd python-todo-cli
python todo.py
```

没有 Git 时，可以在仓库页面选择 Code → Download ZIP，解压后在项目文件夹打开终端，执行 `python todo.py`。Windows 如果找不到 python，可尝试 `py todo.py`。

菜单：

```text
1 添加任务  2 查看任务  3 标记完成  0 退出
```

首次使用按顺序输入：`1` → `学习 Python 列表` → `2` → `3` → `1` → `0`。
重新启动，输入 `2`，应看到 `1. [已完成] 学习 Python 列表`。

每次成功添加或标记完成后会立即保存；查看列表不会修改文件。

## 文件和数据

- `todo.py`：程序入口及全部业务逻辑。
- `tasks.json`：运行时自动生成，和 todo.py 位于同一目录，已加入忽略列表，不提交个人任务。
- `.gitignore`：忽略任务数据、临时文件及 Python 缓存。

一项任务的数据格式：

```json
{"title": "学习 Python 列表", "done": false}
```

文件中存放的是这些任务组成的列表。`title` 是非空字符串，`done` 是布尔值。

## 代码怎样工作

| 部分 | 作用 | 涉及知识 |
| --- | --- | --- |
| `main()` | 显示菜单，读取输入，执行对应操作 | 循环、分支、函数调用 |
| `show_tasks()` | 从 1 开始编号，打印标题和完成状态 | 列表、字典、enumerate |
| `task_index()` | 验证输入并将显示编号转换为列表下标 | 整数转换、范围判断、异常 |
| `load_tasks()` | 读取 JSON，检查数据结构 | 文件读写、类型检查 |
| `save_tasks()` | 先写临时文件，成功后替换原文件 | JSON 序列化、路径操作 |

流程：启动 → 读取数据 → 显示菜单 → 读取用户选择 → 校验输入 → 执行操作 → 必要时保存 → 返回菜单。

为什么编号要减 1：用户看到的第一项编号是 1，但列表第一项的下标是 0。
为什么先检查范围：Python 的下标 -1 表示最后一项，输入 0 后直接减 1 会误改最后一项，不能仅靠捕获 IndexError。
为什么指定数据路径：从另一个目录启动程序时，仍然读写 todo.py 旁边的同一份数据。
为什么使用临时文件：先完成写入再替换，可降低普通写入错误导致原文件被截断的风险；这不等于断电恢复或备份系统。

## 实际开发阶段

1. 基础版本：内存中的添加、查看与退出。
2. 实用功能：完成状态、JSON 保存和重启恢复。
3. 错误处理：空标题、非法编号、数据结构校验和写入失败保护。
4. 文档与忽略规则：补充运行说明、原理、验证结果及学习练习。


## 已执行的检查

助手使用隔离的临时目录运行实际程序，验证以下七组场景通过：

1. 空列表、空标题、未知菜单选项。
2. 中文任务添加和保存。
3. 编号为 0、负数、越界值及非整数时，任务不变。
4. 完成任务、重复完成、重启恢复、从不同目录启动。
5. JSON 损坏或字段类型错误时，报错退出且原文件不被覆盖。
6. 输入结束时正常退出。
7. 临时文件路径不可写时，报告保存失败且保留原数据。

你可以自己复测：先添加两项任务，在“标记完成”时依次输入 `0`、`-1`、`3` 和 `abc`，然后查看列表，两项都应保持未完成。这是值得亲自观察和解释的边界情况。

## 已知限制与故障处理

- 只适合单人、单进程使用；不要同时打开两个实例修改同一份数据。
- 没有编辑、删除、截止日期、搜索和云同步功能。
- 数据是明文文件，不适合存放密码等敏感信息。
- 数据损坏时程序停止，不会自动清空。先备份 tasks.json，再检查 JSON 内容；如果不要旧数据，可将其改名保留后重新启动。
- 保存失败时检查目录权限和磁盘空间，本次失败的修改不会保存。
- 临时文件替换不能保证所有断电或硬件故障下的数据安全，重要数据应另行备份。
